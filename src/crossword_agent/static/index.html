      AN HONEST SCORECARD

      What we measure

      Cell accuracy

      Correct letters or digits ÷ all fillable cells. Empty cells count as incorrect.

      Answer accuracy

      Exactly correct entries ÷ all across and down entries.

      Completion

      Filled cells ÷ all open cells, including wrong answers. Filling the grid does not prove correctness.

      Exact puzzle accuracy

      Evaluated runs with every cell correct and no hard constraint violations ÷ all evaluated runs. Repeat attempts count separately.

      Constraint violations

      Wrong lengths, crossing conflicts, or changed given cells.

      Candidate recall

      How often the correct answer appeared among the proposed candidates.

      Runtime & usage

      Elapsed time, model calls, and tokens. Better answers have a measurable cost.

      Scores compare the original run with your approved key; key quality matters. Historical benchmark results are separate.

      THE APPROACH

      Language proposes. Logic checks.

      One agent coordinates the loop. Each component has a small, explicit responsibility.

      THE SOLVING LOOPBounded. Observable. Reversible.
      A

      Choose the right way to answer.

      The language model proposes alternatives for word clues. Supported arithmetic expressions are evaluated exactly in code, then entered as digit candidates. Numeric answers still have to fit their crossings.

      B

      The grid tests the guess.

      Every shared square must hold the same value. Search tries combinations and backs out of guesses that block other entries. Supplied values stay fixed.

      C

      Some answers need another look.

      The controller revisits unresolved entries. For words with few crossing checks, it can request one independent candidate pass within the remaining budget. This extra review can still be wrong; an answer key is the correctness check.

      SCREENSHOT → STRUCTURED PUZZLE

      Measure the grid. Read the clues.

      OpenCV measures cell borders and grid geometry. GLM vision reads the printed clues and supplied values. The combined puzzle is structurally checked, with bounded repair when needed. Review the preview before solving: valid geometry does not prove a perfect transcription.

      SUPPORTED ANSWER FORMATS

      Words and number crosswords.

      Use one A–Z letter per cell for word puzzles, or one 0–9 digit per cell for numeric puzzles. Blocks and supplied values are supported. Rebus cells, barred grids, and cryptic-specific parsing remain outside the supported format.
