      AN HONEST SCORECARD

      What we measure

      Letter accuracy

      Correct letters ÷ all fillable cells. Empty cells count as incorrect.

      Answer accuracy

      Exactly correct entries ÷ all across and down entries.

      Exact puzzle accuracy

      Puzzles with every letter correct ÷ all evaluated puzzles.

      Constraint violations

      Wrong lengths, crossing conflicts, or changed given letters.

      Candidate recall

      How often the correct answer appeared among the proposed candidates.

      Runtime & usage

      Elapsed time, model calls, and tokens. Better answers have a measurable cost.

      The bundled puzzles are an authored smoke benchmark, not evidence of performance on all crosswords. Reference answers remain outside the solving input. Public puzzle performance may be affected by training data overlap.

      THE APPROACH

      Language proposes. Logic checks.

      One agent coordinates the loop. Each component has a small, explicit responsibility.

      THE SOLVING LOOPBounded. Observable. Reversible.
      A

      The model understands the clue.

      “Financial institution”, four letters, may suggest BANK or FUND. Keeping alternatives lets the rest of the puzzle provide evidence.

      B

      The grid tests the guess.

      Every shared square must hold the same letter. Search tries combinations and backs out of guesses that block other entries.

      C

      The agent knows when to revisit.

      If the candidates cannot produce a full grid, the controller requests more answers. Tentative letters can change; supplied letters stay fixed.

      SCREENSHOT → STRUCTURED PUZZLE

      Extraction is a separate step.

      A vision model reads the grid and clues. You review the extracted JSON, validate its structure, and explicitly use the puzzle before solving. A readable image is still no guarantee of a perfect transcription.

      A PRACTICAL FIRST SCOPE

      Standard English crosswords.

      One A–Z letter per cell. Blocks and supplied letters are supported. Rebus cells, barred grids, and cryptic-specific parsing are outside the first version’s supported format.
